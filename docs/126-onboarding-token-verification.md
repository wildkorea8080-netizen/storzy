# 온보딩 관리자 토큰 검증

온보딩 연결 패널은 토큰을 저장하기 전에 `GET /api/admin/workspaces?limit=1`로 관리자 권한을 확인한다.

- 성공 응답을 받은 토큰만 `sessionStorage`에 저장한다.
- `401`이면 토큰을 저장하지 않고 명확한 오류를 표시한다.
- 빈 입력은 기존 세션 토큰을 제거한다.
- 확인 중에는 버튼을 잠가 중복 요청을 방지한다.
- 성공 후에만 페이지를 새로 불러 온보딩 작업을 재개한다.

검증 요청에는 사용자가 방금 입력한 토큰을 직접 사용하므로 기존에 저장된 잘못된 토큰의 영향을 받지 않는다.
