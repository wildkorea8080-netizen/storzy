# 주문 대조 스케줄 신선도 경보

Shopify가 연결된 워크스페이스에서는 실행 실패뿐 아니라 스케줄러 미설정과 장기 미실행도 운영 장애로 간주한다.

## 경보 조건

- 실행 원장이 없음: `RECONCILIATION_RUN_NEVER`
- 마지막 정상 실행 후 26시간 초과: `RECONCILIATION_RUN_OVERDUE`

기본 운영 주기는 24시간이며 2시간의 실행·스케줄 지연 허용 시간을 더해 26시간을 경계로 사용한다. Shopify 연결이 없는 워크스페이스에는 이 경보를 표시하지 않는다.

최신 실행이 `FAILED`, `PARTIAL` 또는 정체된 `RUNNING`이면 해당 실행 장애 경보가 이미 표시되므로 신선도 경보를 중복 생성하지 않는다. 정상 실행이 완료되면 미실행·지연 경보는 자동으로 사라진다.
