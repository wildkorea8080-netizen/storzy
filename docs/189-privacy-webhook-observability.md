# 개인정보 Webhook 운영 관측

서명 검증을 통과한 Shopify 개인정보 Webhook의 운영 수신 이력을 저장하고 관리자 개인정보 화면에서 확인한다.

- 고유 Webhook 수, 전체 전달 횟수, 중복 횟수, 최근 24시간 수신 수를 집계한다.
- Shopify 연결을 찾지 못한 수신을 `워크스페이스 미연결`로 표시한다.
- 원문 payload와 고객 연락처는 감사 테이블에 저장하지 않는다.
- 위조 서명과 잘못된 헤더 요청은 DB 증폭 공격을 피하기 위해 감사 테이블에 저장하지 않고 HTTP 오류 로그만 사용한다.
- 스토어 삭제가 완료되면 수신 이력의 워크스페이스, Webhook ID, 스토어 도메인을 익명화한다.
