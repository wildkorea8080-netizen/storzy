# 주문 대조 경보 집계와 워크스페이스 범위

운영 현황의 `확인 필요` 숫자는 활성 주문 대조 이슈뿐 아니라 주기 실행 상태 장애도 한 건으로 포함한다.

`counts.reconciliation.RUN_HEALTH`는 다음 조건을 모두 만족할 때 `1`이다.

- 현재 워크스페이스에 활성 Shopify 연결이 있음
- 주기 대조 미실행, 실패, 부분 실패, 2시간 이상 정체 또는 26시간 이상 지연 상태임

정상 상태이거나 Shopify 연결이 없으면 `RUN_HEALTH`는 생성하지 않는다. 화면은 `counts.reconciliation` 합계를 사용하므로 이슈 수와 실행 장애 수가 확인 필요 지표에 함께 반영된다.

전역 실행 원장의 실패 경보도 활성 Shopify 연결이 있는 현재 워크스페이스에만 반환한다. 따라서 Shopify를 사용하지 않는 워크스페이스에 다른 스토어의 실행 장애가 노출되지 않는다.
