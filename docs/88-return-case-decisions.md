# 반송 케이스 처리 결정

반송 주문은 일반 주문 재승인 경로와 분리해 고객 지원 결정을 명시적으로 기록한다.

- `REQUIRE_REFUND`: 환불 처리가 필요함
- `REVIEW_RESHIPMENT`: 재배송 여부와 추가 비용 검토가 필요함
- `RESOLVE`: 외부 환불·지원 처리가 끝났음을 확인

각 작업은 담당자, 1~500자 사유, 멱등키, 이전·이후 상태를 감사 이력으로 저장한다. `RESOLVE`가 완료되면 주문은 `RETURN_RESOLVED`로 변경되어 활성 반송 큐에서 제외된다.

이 워크플로는 Shopify 환불이나 Printful 재제작을 자동 실행하지 않는다. 실제 비용을 발생시키는 작업은 별도 공급사 확인 이후 수행해야 한다.
