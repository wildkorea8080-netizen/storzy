# 운영 현황 상태·알림 UX

운영 현황은 7단계 여정, 핵심 지표, 파이프라인 상태, 확인 필요 알림의 네 영역으로 구성한다.

파이프라인 상세는 원시 상태 코드 대신 승인, 검토 필요, 생성 중, 대기, 처리 중, 완료, 실패, 자동 중단, 제출 완료 등의 한국어 상태 칩을 표시한다. 성공 상태는 초록색, 진행·대기 상태는 노란색, 실패·중단 상태는 빨간색으로 구분한다.

확인 필요 알림은 `ORDER`, `SHOPIFY_PUBLICATION`, `PRINTFUL_MOCKUP`, `PRINTFUL_ORDER`를 주문 예외, Shopify 게시, Printful 목업, Printful 주문으로 변환한다. 주문 알림의 JSON 사유 배열도 배송 불가 국가, 공급 원가 급등, 디자인 파일 누락 같은 운영 문구로 해석한다.

원시 코드와 집계 API는 변경하지 않는다. 번역은 관리자 화면 표현 계층에서 수행하며 미등록 코드는 진단 가능성을 위해 원본 값을 그대로 표시한다.
