# 관리자 브랜드 온보딩 한국어 UX

브랜드 온보딩은 STORZY의 첫 사용자 단계이므로 질문, 생성 상태, 검수 안내와 승인 확인을 모두 한국어로 제공한다. 12개 질문의 기본 예시는 `Seoul Side Studio`를 기준으로 작성하며 대상 국가처럼 외부 연동 계약에 쓰이는 값은 ISO 국가 코드를 유지한다.

원시 상태 코드는 화면에서 다음과 같이 표시한다.

- `GENERATING`: AI 생성 중
- `REVIEW_REQUIRED`: 검토 필요
- `APPROVED`: 승인 완료
- `SUPERSEDED`: 이전 버전
- `GENERATION_FAILED`: 생성 실패

프로필 생성 중에는 JSON 편집과 승인을 비활성화한다. 검토 필요 상태가 되면 수정본 저장과 승인이 가능하며, 승인 전에는 해당 프로필이 이후 상품 추천과 스토어 생성의 기준이 된다는 확인을 받는다. 관리자 편집은 기존 revision을 변경하지 않고 새 revision을 생성하는 불변 이력 정책을 유지한다.
