# 수동 연결 해제 후 Shopify 앱 삭제

운영자가 STORZY에서 먼저 Shopify 연결을 해제한 뒤 Shopify에서 앱을 삭제해도 후속 개인정보 삭제 귀속이 유지된다.

- 앱 삭제 수신은 활성 연결을 우선하고, 없으면 같은 도메인의 가장 최근 연결 해제 이력을 찾는다.
- 이미 `DISCONNECTED`이면 파기된 자격 증명을 다시 쓰거나 중복 연결 감사를 만들지 않는다.
- 새 앱 삭제 수신 원장에 기존 연결과 워크스페이스만 연결한다.
- 이 원장을 통해 후속 `shop/redact`가 원래 워크스페이스로 전달된다.
