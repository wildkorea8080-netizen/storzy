# 관리자 미리보기 자동화 UX

주문 운영 화면은 관리자 토큰과 워크스페이스를 연결한 뒤 다음 동작을 제공한다.

- `주문 생성`: 수량 1~5개를 지정해 게시 상품 기반의 Shopify 주문을 생성한다.
- `배송 처리`: 최근 제출 완료 주문에 Printful 배송 이벤트를 발생시킨다.
- 진행 상태: `SUBMITTED` 주문 수와 Shopify Fulfillment 완료 수를 운영 현황 API에서 표시한다.

두 버튼은 미리보기 전용 API만 호출한다. 운영 외부 계정이나 과금 작업에는 접근하지 않으며, 각 단계는 기존 정책 엔진과 worker를 통해 비동기로 처리된다.
