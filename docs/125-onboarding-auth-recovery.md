# 온보딩 관리자 연결 복구

브랜드 온보딩 화면 상단에 관리자 API 토큰 연결 패널을 제공한다. 사용자는 관리자 메인 화면을 거치지 않고 직접 온보딩 URL에 들어오거나 브라우저 세션이 초기화된 경우에도 토큰을 다시 저장하고 작업을 계속할 수 있다.

- 토큰은 브라우저 `sessionStorage`에만 저장한다.
- 저장 후 페이지를 새로 불러 기존 온보딩 요청을 정상 재개한다.
- 토큰 값 자체는 화면에 표시하지 않고 password 입력으로 처리한다.
- 동일 출처 `/api/` 요청에만 Authorization 헤더를 추가한다.
- 외부 요청과 정적 자산에는 토큰을 전달하지 않는다.
