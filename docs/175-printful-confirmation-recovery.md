# Printful 주문 확정 응답 유실 복구

`READY_CONFIRM` 작업은 Printful 확정 API를 호출하기 전에 원격 주문 상태를 조회한다.

- `draft`: 현재 worker가 lease를 재검증한 뒤 확정한다.
- `pending`, `inreview`, `inprocess`: 이전 확정 요청이 이미 성공한 것으로 보고 추가 확정 없이 로컬 작업과 주문을 성공 처리한다.
- 그 외 상태: 자동 확정을 중단하고 운영자 검토 상태로 전환한다.

이 흐름은 Printful이 확정을 완료한 직후 네트워크 단절이나 프로세스 종료로 응답이 유실되어도 재시도에서 같은 주문을 다시 확정하지 않도록 한다.
