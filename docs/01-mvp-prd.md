# MVP 제품 요구사항

## 1. 목표

비개발자인 브랜드 운영자가 온보딩부터 POD 상품 공개 준비까지 반복 작업을 줄이고, 모든 외부 반영을 검수 가능한 방식으로 수행하게 한다.

MVP의 핵심 성공 경험은 다음과 같다.

> 사용자가 브랜드 질문에 답하고 디자인 파일을 올리면, 시스템이 적합한 상품과 콘텐츠·목업·스토어 페이지 초안을 만들고, 사용자가 승인한 결과만 Shopify에 등록한다. 이후 유효한 주문은 Printful로 전달하고 예외 주문은 관리자 검수 큐로 보낸다.

## 2. 대상 사용자

- **브랜드 운영자**: 브랜드·가격·상품·콘텐츠를 결정하고 게시를 승인한다.
- **운영 관리자**: 연동 오류와 주문 예외를 검토하고 재처리 또는 취소한다.
- **스토어 고객**: Shopify storefront에서 상품을 구매하고 배송 상태를 확인한다.

MVP에서는 다중 조직의 세밀한 역할 권한, 협업 승인 체계, 자체 결제·체크아웃은 제외한다.

## 3. 핵심 사용자 흐름

1. 사용자가 계정 및 브랜드 작업공간을 만든다.
2. 10~15개 온보딩 질문에 답한다.
3. AI가 답변을 `BrandProfile` 스키마로 구조화한다.
4. 사용자가 프로필을 확인·수정·승인한다.
5. 규칙 엔진이 Printful 카탈로그 데이터와 비용을 사용해 상품 후보를 점수화한다.
6. AI가 후보별 선정 이유와 상품 콘텐츠를 생성한다.
7. 사용자가 템플릿, 상품, 디자인 적용, 가격, 콘텐츠를 검수한다.
8. 시스템이 목업 생성 완료 후 Shopify 게시 초안을 보여준다.
9. 사용자 승인 시에만 Shopify에 상품·컬렉션·콘텐츠를 반영한다.
10. 결제 완료 주문 Webhook을 수신하면 검증 후 Printful 주문을 생성한다.
11. 제작·배송 이벤트를 받아 Shopify fulfillment에 추적 정보를 반영한다.

## 4. MVP 기능 범위

### P0 — 출시 필수

- 브랜드 온보딩 및 구조화된 Brand Profile 생성·수정·버전 관리
- 3개 스토어 템플릿 선택 및 설정값/콘텐츠 생성
- 홈, Shop, Collections, About, FAQ, Shipping, Returns, Contact 초안
- Printful 카탈로그 동기화와 상품 후보 점수 계산
- 상품별 영·한 제목, 설명, 특징, 소재·사이즈, SEO, 태그, 컬렉션, SNS 문구 생성
- 디자인 파일 업로드, 유효성 검사, 제품 배치 정보 연결
- Printful 목업 비동기 생성 및 결과 확인
- Shopify OAuth 연결, 상품/변형/이미지/컬렉션/SEO 등록
- 게시 전 변경 내역 검수와 명시적 승인
- Shopify 주문 Webhook 수신, 중복 제거, 주문 안전성 검증
- Printful 주문 생성 및 상태·송장 동기화
- 예외 주문 큐, 수동 승인/거절/재시도, 감사 로그

### P1 — MVP 안정화 후

- 템플릿 5개로 확대
- 대량 상품 생성 및 비동기 Shopify `productSet`
- 국가별 가격·배송 문구 최적화
- 생성 콘텐츠 A/B 대안
- 운영 지표 대시보드와 비용 알림

### 제외

- AI의 Liquid/theme 코드 직접 수정
- 자체 storefront, 결제, 세금 계산 또는 WMS
- 무검수 자동 상품 공개
- 판매량 예측을 가장한 근거 없는 LLM 추천
- 반품 승인 및 고객 지원의 완전 자동화
- 여러 POD 공급사 동시 라우팅

## 5. 템플릿 전략

MVP는 검증된 Shopify 테마 구성 위에 템플릿별 설정 프리셋을 적용한다. AI는 허용 목록에 있는 색상 토큰, 섹션 선택, 텍스트, 이미지 참조만 생성한다.

초기 템플릿은 `Minimal Fashion`, `Korean Street`, `Creator Merchandise` 3개로 제한한다. Outdoor와 Tourist Souvenir는 P1 후보이다.

## 6. 성공 지표

| 지표 | MVP 목표 |
|---|---:|
| 온보딩 시작 → 승인된 Brand Profile | 80% 이상 |
| 프로필 승인 → Shopify 초안 생성 | 중앙값 15분 이하(외부 비동기 작업 포함) |
| 구조화 출력 스키마 검증 성공 | 99% 이상(재시도 포함) |
| 승인되지 않은 외부 게시 | 0건 |
| 동일 주문의 Printful 중복 생성 | 0건 |
| 정상 Webhook 수신 → 큐 적재 | p95 2초 이하 |
| 자동 처리 주문 중 잘못 승인된 주문 | 0.1% 미만, 목표 0건 |

## 7. 수용 기준

- 사용자는 생성값을 모두 수정할 수 있고 승인 전/후 버전을 구분할 수 있다.
- 금액과 마진은 정수 minor unit(예: USD cents) 기반 코드로 계산한다.
- 외부 쓰기는 동일 idempotency key로 재실행해도 중복 결과를 만들지 않는다.
- Webhook은 서명 검증 후 빠르게 2xx 응답하고 실제 처리는 큐에서 수행한다.
- 차단 규칙 중 하나라도 실패하면 Printful 주문을 만들지 않는다.
- 외부 시스템 ID와 요청/응답 추적 ID를 감사 로그에서 찾을 수 있다.
