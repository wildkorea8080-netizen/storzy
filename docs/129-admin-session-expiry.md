# 관리자 세션 만료 복구

모든 관리자 페이지는 API 응답이 `401`이고 오류 코드가 `ADMIN_AUTH_REQUIRED`이면 저장된 관리자 토큰을 제거하고 재연결 안내 배너를 표시한다.

- 응답 본문은 `clone()`으로 확인하므로 각 화면의 기존 오류 처리 흐름을 방해하지 않는다.
- 관리자 인증 오류일 때만 토큰을 제거한다.
- Shopify·Printful Webhook 오류와 일반 `401` 응답은 세션 만료로 처리하지 않는다.
- 한 페이지에서 여러 요청이 동시에 실패해도 배너는 한 번만 표시한다.
- 화면에 토큰 입력 필드가 있으면 만료된 값을 즉시 비운다.

공통 스크립트는 각 관리자 페이지의 기능 스크립트보다 먼저 로드되어 초기 API 요청부터 세션 만료를 감지한다.
