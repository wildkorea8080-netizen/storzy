# 실패한 워크스페이스 재대조

주기 실행 이력에서 현재 워크스페이스 결과가 `FAILED`이면 `현재 워크스페이스 다시 대조` 버튼을 표시한다.

재대조는 실패한 실행의 `window_hours`를 그대로 사용해 현재 워크스페이스의 Shopify 주문만 다시 조회한다. 실행 전 다음 영향을 명시적으로 확인한다.

- Shopify 주문을 읽고 대조 이슈를 생성·갱신·자동 해결한다.
- 상품 제작, Printful 주문 제출과 Shopify 데이터 변경은 수행하지 않는다.
- 다른 워크스페이스는 조회하지 않는다.

재대조 스캔의 처리자는 `admin-ui-retry`로 기록되어 주기 실행과 관리자의 복구 작업을 구분할 수 있다. 성공하면 화면을 `처리 필요` 탭으로 전환하고 원격 주문 수, 불일치 수와 자동 해결 수를 표시한다.
