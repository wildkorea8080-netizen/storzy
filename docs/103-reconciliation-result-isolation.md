# 주문 대조 실행 결과 격리와 오류 정제

마지막 주기 실행 상태 API는 전체 실행의 집계 수치와 요청한 워크스페이스의 결과만 반환한다. 다른 워크스페이스 ID, 조회 주문 수와 오류는 응답에 포함하지 않는다.

## 오류 저장 정책

- Shopify access token과 일치하는 문자열은 `[REDACTED]`로 치환한다.
- 줄바꿈과 탭을 공백으로 치환한다.
- 최대 500자로 제한한다.
- 알 수 없는 비문자 오류는 `UNKNOWN_ERROR`로 기록한다.

관리 화면은 현재 워크스페이스의 성공 여부와 정제된 오류만 표시한다. 실행 원장 내부에는 운영 진단을 위해 워크스페이스별 결과가 남지만 API는 JSON 배열에서 요청 워크스페이스 항목 하나만 선택한다.
