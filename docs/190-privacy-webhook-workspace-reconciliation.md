# 개인정보 Webhook 워크스페이스 재연결

Shopify 연결 전에 도착해 워크스페이스가 없는 개인정보 요청을, 이후 연결된 Shopify 스토어 도메인과 정확히 일치할 때 관리자 작업으로 귀속한다.

- 클라이언트가 전달한 도메인을 신뢰하지 않고 서버에 저장된 `CONNECTED` Shopify 연결의 도메인을 사용한다.
- 아직 워크스페이스가 없는 요청과 수신 이력만 변경한다.
- 요청 귀속과 수신 이력 귀속을 하나의 트랜잭션에서 처리한다.
- 각 요청에 `RECONCILE_WORKSPACE` 감사 작업을 기록한다.
- 활성 워크스페이스와 관리자 인증이 모두 필요하다.
