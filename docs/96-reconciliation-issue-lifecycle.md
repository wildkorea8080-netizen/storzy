# 주문 대조 이슈 생명주기

같은 Shopify 주문과 이슈 유형에 대해 활성 상태(`OPEN`, `ACKNOWLEDGED`)의 대조 이슈는 하나만 유지한다.

## 반복 대조

- 동일한 불일치가 다시 발견되면 새 이슈를 만들지 않는다.
- 기존 이슈의 최신 scan, 로컬 값, Shopify 값과 원격 수정 시각을 갱신한다.
- 해결된 과거 이슈는 감사 이력으로 보존한다. 이후 같은 문제가 다시 발생하면 새 이슈를 생성한다.

## 자동 해결

대조 범위에 포함된 주문이 다음 스캔에서 정상 상태로 확인되면 기존 활성 이슈를 자동으로 `RESOLVED` 처리한다.

- 감사 작업: `AUTO_RESOLVE_MATCHED`
- 처리자: 해당 대조 스캔을 실행한 관리자
- 사유: `재대조에서 Shopify와 로컬 상태 일치 확인`
- 자동 해결 건수는 대조 API의 `autoResolved`로 반환하고 관리 화면 결과에 표시한다.

마이그레이션 045는 기존 중복 활성 이슈가 있다면 가장 최근 이슈만 남기고 나머지를 해결 상태로 전환한 후 부분 고유 인덱스를 생성한다.
