# Shopify 앱 삭제 안전 처리

`app/uninstalled` Webhook을 수신하면 서명과 필수 헤더를 검증한 뒤 해당 Shopify 연결의 자격 증명을 즉시 파기한다.

- Webhook ID를 별도 저장해 재전송을 멱등 처리한다.
- 연결 상태를 `DISCONNECTED`로 변경하고 암호문·IV·인증 태그를 무작위 값으로 교체하며 키 버전을 `destroyed`로 설정한다.
- `DISCONNECTED` 연결 감사 기록을 남긴다.
- 기존 DB 트리거가 워크스페이스 주문 자동화를 즉시 비활성화한다.
- 알 수 없는 스토어의 서명 유효 이벤트도 성공 수신 처리하되 연결 데이터는 변경하지 않는다.
- 로컬 미리보기는 운영 자격 증명과 분리된 고정 개발용 암호화 키를 주입해 실제 Webhook 경로를 검증한다.
