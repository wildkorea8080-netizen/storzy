# 안전 재수신 주문의 제작 재개 게이트

Shopify 누락 주문을 안전 재수신하면 `RECONCILIATION_REPLAY_REVIEW` 사유와 `HELD` 상태로 저장된다.

이 주문은 일반 `MANUAL_APPROVE` 작업으로 재개할 수 없다. 관리자는 주문 상세에서 `REVALIDATE`를 실행해야 하며, 이 작업은 저장된 Shopify 원문과 현재 상품 매핑을 기준으로 다음 항목을 다시 검사한다.

- 배송 국가와 주소 완전성
- 결제 상태
- 상품 변형 매핑의 유일성
- 디자인 파일 존재 여부
- 주문 수량과 고액 주문 한도
- 현재 원가, 승인 원가와 마진

모든 규칙을 통과해 `READY`가 된 경우에만 Printful 작업을 생성한다. 검증 실패 시 주문은 `HELD` 또는 `WAITING`에 남고 실패 사유를 최신 정책 결과로 교체한다. 거절은 사유를 남긴 명시적 관리자 작업으로 계속 허용한다.
