# E2E 파일럿 준비 체크리스트

연동 설정 화면은 실제 Shopify·Printful 파일럿 실행에 필요한 여섯 단계를 기존 운영 데이터에서 자동 집계한다.

1. 승인된 브랜드 프로필 존재
2. Shopify 연결 완료
3. Printful 연결 완료
4. 양쪽 Webhook 수신 준비 완료
5. Shopify 상품 게시 성공 이력 존재
6. Printful로 제출된 테스트 주문 존재

완료 수와 진행률을 표시하고, 아직 완료되지 않은 첫 단계를 다음 작업으로 강조한다. 각 단계는 온보딩, 연동 설정, 스토어 또는 주문 화면으로 바로 이동한다.

체크리스트는 비밀키를 조회하지 않는다. 관리자 인증이 적용된 연동 상태, Webhook 준비 상태, 운영 Overview API만 병렬 조회한다.
