# 연동 연결 해제 및 자격 증명 폐기

## 목적

워크스페이스에 암호화 저장된 Shopify 또는 Printful 연결을 관리자가 안전하게 해제한다. 환경 변수로 주입된 운영 연결은 이 화면에서 해제하지 않는다.

## 처리 흐름

1. 연동 설정 화면은 상태 API의 `source`가 `WORKSPACE`인 연결에만 **저장된 연결 해제** 버튼을 표시한다.
2. 서버가 공급사별 진행 중 작업 수를 점검한다. Printful은 주문·목업 작업, Shopify는 스토어 발행·배송정보 반영 작업을 확인한다.
3. 진행 중 작업이 있으면 버튼을 잠그고 작업 수를 표시한다. POST 요청 시에도 다시 점검하여 `409 INTEGRATION_HAS_ACTIVE_WORK`로 차단한다.
4. 관리자는 1~500자의 해제 사유를 입력하고 폐기를 재확인한다.
5. 서버는 워크스페이스 활성 상태와 관리자 인증을 확인한다.
6. 저장된 암호문, IV, 인증 태그를 새로운 임의 바이트로 덮어쓰고 키 버전을 `destroyed`로 변경한다.
7. 연결 상태를 `DISCONNECTED`로 바꾸고 메타데이터를 제거한다.
8. 담당자, 이전/이후 상태, 해제 사유를 `integration_connection_actions`에 기록한다.

이 작업 후 기존 자격 증명은 애플리케이션을 통해 복호화할 수 없다. 다시 사용하려면 Shopify OAuth 또는 Printful 연결 등록을 새로 수행해야 한다.

## API

`POST /api/workspaces/{workspaceId}/integrations/{shopify|printful}/disconnect`

같은 경로에 `GET`을 호출하면 `safe`, `blockingCount`, 공급사별 `blockers`가 반환된다.

```json
{
  "actorId": "admin-ui",
  "reason": "공급사 계정 교체"
}
```

응답에는 공급사, 연결 상태, 계정 표시명, 갱신 시각만 포함하며 자격 증명은 반환하지 않는다.

## 운영 주의사항

- `source: ENVIRONMENT` 연결은 배포 환경의 비밀 관리 시스템에서 제거하고 서비스를 재시작해야 한다.
- 감사 기록은 자격 증명을 포함하지 않는다.
- 해제 전에 진행 중 주문과 웹훅 처리 여부를 확인한다.
- 데이터베이스 백업에는 과거 암호문이 남을 수 있으므로 백업 보존·폐기 정책을 별도로 적용한다.
