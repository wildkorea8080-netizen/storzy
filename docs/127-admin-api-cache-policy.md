# 관리자 API 캐시 정책

`/api/` 아래의 비공개 API 응답에는 성공·오류 여부와 관계없이 다음 헤더를 적용한다.

- `Cache-Control: no-store, private`
- `Pragma: no-cache`

이 정책은 브랜드 프로필, 상품 검수, 연동 계정 메타데이터, 주문 및 개인정보 운영 데이터가 브라우저 캐시나 공유 프록시에 남는 것을 방지한다. 인증 실패 응답에도 동일하게 적용하여 보호 경로의 응답 특성이 캐시에 저장되지 않게 한다.

공개 스토어 미리보기 API인 `/api/preview/`는 이 정책에서 제외한다. 향후 공개 응답은 별도의 ETag 및 짧은 TTL 정책으로 최적화할 수 있다.
