# Shopify 스토어 단일 워크스페이스 소유권

동일한 Shopify 스토어 도메인이 여러 워크스페이스에 동시에 연결되면 주문과 개인정보 요청의 귀속이 모호해진다. 연결 상태의 Shopify 계정은 하나의 워크스페이스만 소유하도록 제한한다.

- 도메인은 대소문자를 구분하지 않고 비교한다.
- 연결 트랜잭션에서 도메인별 PostgreSQL advisory lock을 획득해 동시 연결 경쟁을 직렬화한다.
- 다른 워크스페이스의 활성 연결이 있으면 `SHOPIFY_ACCOUNT_ALREADY_CONNECTED`로 거부한다.
- DB partial unique index가 애플리케이션 우회 쓰기에도 동일한 불변식을 보장한다.
- 연결 해제된 과거 감사 행은 유지할 수 있으며 새 워크스페이스로 이전하려면 기존 연결을 먼저 해제해야 한다.
