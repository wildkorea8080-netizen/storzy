# 상품 검수 API 인증 경계

상품 후보, 디자인 검수, 상품 콘텐츠 검수 API는 관리자 Bearer 토큰을 요구한다. 인증 검사는 요청 본문 파싱과 서비스 호출보다 먼저 실행한다.

보호 범위는 실제 지원 경로로 제한한다.

- 상품 후보 목록과 승인·제외 결정
- 디자인 파일 조회, 목업 재생성, 해상도 정책 예외 승인
- 상품 콘텐츠 목록과 수정 revision 생성
- 콘텐츠 revision 승인

부분 문자열 검사를 사용하지 않고 전체 경로 패턴을 검사한다. 따라서 이름이 비슷한 미등록 경로까지 인증 미들웨어가 가로채는 문제를 방지하면서, 현재 제공하는 8개 검수 경로는 모두 인증 없이 `401`을 반환한다.
