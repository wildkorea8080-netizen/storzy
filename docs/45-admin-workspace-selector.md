# 관리자 워크스페이스 선택기

## 목적

관리자가 매 페이지에서 UUID를 복사해 입력하지 않고 최근 워크스페이스를 이름으로 찾아 연결할 수 있게 한다. 선택한 UUID와 관리자 토큰은 기존과 같이 세션 범위에서 공유되어 메뉴 이동 시 같은 작업 공간을 유지한다.

## API

```http
GET /api/admin/workspaces?limit=100
Authorization: Bearer {adminToken}
```

응답은 최근 갱신 순서의 `id`, `name`, `status`, `createdAt` 목록이다. `limit`은 1~100만 허용하며 관리자 Bearer 인증을 적용한다.

## 화면 동작

- 모든 관리자 페이지의 기존 워크스페이스 UUID 입력창에 공통 `datalist`를 연결한다.
- 옵션에는 워크스페이스 이름과 상태를 표시하고 실제 값은 UUID를 사용한다.
- 기존 UUID 직접 입력은 유지한다.
- 선택된 워크스페이스 이름을 상단 환경 표시 영역에 노출한다.
- 한 개의 워크스페이스만 존재하고 선택값이 없으면 자동으로 채운다.
- 토큰이 없거나 목록 조회가 실패해도 기존 직접 연결 흐름은 영향을 받지 않는다.

## 보안

목록 API는 서버의 기존 관리자 토큰 검증을 사용한다. 토큰은 브라우저 `sessionStorage`에만 유지되며 워크스페이스 목록이나 HTML에 포함하지 않는다.
