# 주문 대조 주기 실행 이력

주문 대조 화면의 `주기 실행` 탭은 최근 20개 실행을 최신순으로 표시한다.

각 실행에는 다음 정보가 포함된다.

- 실행 상태와 시작 시각
- 조회 시간 범위
- 전체·성공·실패 워크스페이스 수
- 현재 워크스페이스의 성공 여부와 조회 주문 수
- 현재 워크스페이스의 정제된 오류

API는 `GET /api/workspaces/:workspaceId/order-reconciliation/schedule-history?limit=20`이며 최대 50건까지 조회할 수 있다. 실행 원장의 전체 `results` 배열은 반환하지 않고 요청한 워크스페이스 결과 하나만 JSON에서 선택한다.

이력 조회는 읽기 전용이며 실행 재시도나 Shopify API 호출을 발생시키지 않는다.
