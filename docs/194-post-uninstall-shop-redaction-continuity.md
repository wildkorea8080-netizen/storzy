# 앱 삭제 후 `shop/redact` 연속성

Shopify 앱 삭제로 연결 자격 증명을 파기한 뒤에도 후속 `shop/redact` 요청을 원래 워크스페이스에 귀속할 수 있어야 한다.

- 고객 단위 개인정보 요청은 계속 현재 `CONNECTED` Shopify 연결만 사용한다.
- 스토어 삭제 요청은 최근 7일 이내 `app/uninstalled` 수신 원장의 워크스페이스를 우선 사용한다.
- 최근 앱 삭제 원장이 없으면 현재 활성 연결 조회로 대체한다.
- 스토어 삭제가 완료되면 앱 삭제 원장의 Webhook ID, 도메인, 연결 ID와 워크스페이스 ID를 함께 익명화한다.
- 원장은 원문 payload나 Shopify 자격 증명을 저장하지 않는다.
