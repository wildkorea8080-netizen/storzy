# 관리자 주문·배송 운영 UX

주문 운영 화면은 자동화 진행과 예외 검토를 분리해서 보여준다.

- 진행 영역: Shopify 주문 검증, Printful 제작 요청, Shopify 배송 반영의 3단계와 완료 건수를 표시한다.
- 예외 영역: `HELD`, `WAITING` 주문만 모아 상태, 상품 수량, 주문 금액, 예상 마진과 자동 중단 사유를 보여준다.
- 상세 검토: 주문 원가와 배송 국가, 옵션 매핑, 디자인 등록 여부를 확인하고 정책 재검증, 수동 승인, 거절을 실행한다.

원시 정책 코드는 판매가가 원가보다 낮음, 배송 불가 국가, 배송지 주소 확인 필요, 품절, 공급 원가 급등, 주문 한도 초과, 디자인 누락, 옵션 매핑 오류, 결제 대기, 중복 주문이라는 운영자용 문구로 변환한다. 원본 코드는 사유 태그의 `title` 속성에 남겨 진단 가능성을 보존한다.

수동 승인과 거절에는 사유가 필수다. 정책 재검증은 원본 Shopify webhook과 현재 상품 매핑을 다시 평가하며 별도 사유 없이 실행할 수 있다.
