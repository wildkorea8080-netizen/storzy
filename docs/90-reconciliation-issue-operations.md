# 주문 Reconciliation 이슈 운영

대조 스캔에서 발견한 불일치를 운영자가 확인하고 해결 완료로 기록하는 흐름이다.

- `ACKNOWLEDGE`: 담당자가 이슈를 확인하고 조사 중임을 기록
- `RESOLVE`: Shopify와 로컬 상태를 별도 절차로 확인·복구한 뒤 해결 근거를 기록

각 작업은 담당자, 1~500자 사유, 멱등키, 이전·이후 상태를 감사 이력으로 남긴다. 해결된 이슈는 활성 목록에서 제외된다.

이 작업 자체는 주문 상태를 변경하거나 Printful 주문을 재생하지 않는다. 누락 주문 재생은 원본 Shopify 주문을 다시 검증하고 비용 발생 전 차단 규칙을 통과시키는 별도 기능으로 구현해야 한다.
