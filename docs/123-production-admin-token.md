# 운영 관리자 토큰 시작 검증

운영 환경(`NODE_ENV=production`)에서는 `ADMIN_API_TOKEN`이 필수이며 공백 제거 후 최소 32자여야 한다. 조건을 만족하지 않으면 HTTP 서버와 데이터베이스 연결을 구성하기 전에 애플리케이션 시작을 중단한다.

개발 및 테스트 환경에서는 기존 로컬 작업 흐름을 위해 토큰을 선택 사항으로 유지한다. 미리보기 실행은 `preview-admin`을 명시적으로 설정하므로 관리자 API가 계속 보호된다.

이 검증은 운영 설정 누락으로 관리자 API가 무인증 상태로 공개되는 fail-open 배포를 방지한다. 실제 배포 토큰은 저장소나 이미지에 포함하지 않고 배포 플랫폼의 비밀 저장소에서 주입해야 한다.
