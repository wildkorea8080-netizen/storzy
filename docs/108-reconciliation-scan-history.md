# 주문 대조 스캔 이력

주문 관리 화면에서 현재 워크스페이스의 최근 대조 스캔을 확인할 수 있다.

- Shopify 원격 주문 수
- 로컬 주문 일치 수
- 불일치 수
- 누락 주문·취소 상태·결제 상태의 유형별 불일치 수
- 조회 시작 시각과 실제 실행 시각
- 실행자 (`admin-ui`, `admin-ui-retry`, `scheduler` 등)

API는 `GET /api/workspaces/:workspaceId/order-reconciliation/scans?limit=50`이며 최대 100건을 반환한다. 조회는 읽기 전용이고 Shopify API 재호출이나 주문 상태 변경을 일으키지 않는다.

유형별 건수는 이슈 행을 나중에 재집계하지 않고 스캔 발생 시점에 고정 저장한다. 같은 이슈가 다음 스캔에서 다시 발견되어 최신 스캔으로 이동하더라도 과거 스캔의 통계는 변경되지 않는다.
