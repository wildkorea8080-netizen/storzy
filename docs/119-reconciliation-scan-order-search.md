# 주문 대조 스캔 Shopify 주문 검색

스캔 상세에서 Shopify 주문 ID 일부를 검색할 수 있다. 검색은 불일치 유형 필터와 함께 적용되며 결과 안에서 100건 단위로 페이지네이션한다.

`orderQuery`는 공백 제거 후 최대 100자다. 서버는 검색어를 `LIKE` 패턴으로 조합하지 않고 `position(lower($6) in lower(shopify_order_id))`의 바인딩 파라미터로 전달한다. 따라서 `%`와 `_`가 와일드카드로 해석되지 않는다.

검색어를 변경하면 표시된 상세와 페이지 위치를 초기화한다. Enter를 누르면 첫 번째 스캔의 상세 검색을 실행한다.
