# 주문 대조 처리 이력

주문 대조 화면은 현재 처리해야 하는 이슈와 최근 감사 이력을 분리해 제공한다.

## API

`GET /api/workspaces/:workspaceId/order-reconciliation/history?limit=50`

- 관리자 인증이 필요하다.
- `limit`은 1~100으로 제한한다.
- 이슈 상태, Shopify 주문 ID, 생성·해결 시각과 연결된 모든 감사 작업을 최신순으로 반환한다.
- 감사 작업에는 작업 종류, 처리자, 사유, 이전·이후 상태와 처리 시각이 포함된다.

## 화면

주문 관리 화면의 Shopify 주문 상태 대조 영역에서 다음 탭을 제공한다.

- `처리 필요`: 아직 열려 있거나 확인 중인 대조 이슈
- `처리 이력`: 확인, 수동 해결, 누락 주문 재수신, 취소 상태 반영, 결제 상태 반영 기록

이력 조회는 읽기 전용이며 기존 감사 레코드를 수정하거나 삭제하지 않는다.
