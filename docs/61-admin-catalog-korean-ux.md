# 관리자 상품·콘텐츠 검수 한국어 UX

상품 검수 화면은 정량 점수 엔진의 결과와 AI 콘텐츠를 두 단계로 분리한다.

1. 상품 후보에서는 종합 점수, 예상 마진율, 권장 판매가, 예상 원가와 세부 평가 점수를 확인하고 승인 또는 제외한다.
2. 상품 콘텐츠에서는 영문 판매명과 한국어 관리명, 설명, 태그와 revision 출처를 확인하고 JSON 수정본을 만들거나 승인한다.

상태 코드는 검토 전, 승인 완료, 거절, 자동 제외, 초안, AI 생성 중, 대기, 이전 버전으로 변환한다. 후보 제외에는 사유가 필요하며, 콘텐츠 승인 전에는 해당 revision이 목업 생성과 Shopify 게시의 기준이 된다는 확인을 받는다.

점수 엔진과 승인 API 계약은 변경하지 않는다. UI는 원시 `scoreBreakdown` 키를 예상 마진, 타깃 적합성, 배송 경쟁력, 디자인 적용성, 옵션 다양성, 반품 안정성이라는 운영자용 표현으로 변환한다.

점수 엔진의 `returnSafety`는 반품 안정성으로 표시한다. `eligibility`가 `ELIGIBLE`이 아닌 후보는 아직 결정되지 않았더라도 검토 전으로 오해하지 않도록 자동 제외 상태를 우선 표시한다.
