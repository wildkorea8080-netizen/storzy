# Shopify 연결 시 개인정보 요청 자동 재연결

Shopify OAuth 연결 또는 자격 증명 갱신으로 연결 정보가 저장될 때, 동일 도메인으로 미리 수신된 개인정보 요청과 Webhook 이력을 자동으로 워크스페이스에 귀속한다.

- Shopify 연결 저장과 개인정보 요청 재연결은 동일 DB 트랜잭션에서 커밋된다.
- `workspace_id IS NULL`인 데이터만 대상으로 하며 기존 귀속은 변경하지 않는다.
- 저장된 Shopify 계정 도메인의 대소문자를 정규화해 정확히 일치하는 데이터만 처리한다.
- 자동 귀속된 각 요청에 `RECONCILE_WORKSPACE` 감사 작업을 기록한다.
- Printful 연결에서는 개인정보 재연결 쿼리를 실행하지 않는다.
- 관리자 수동 재연결은 과거 장애나 운영 복구를 위한 보조 수단으로 유지한다.
