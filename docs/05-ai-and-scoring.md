# AI 생성 및 상품 점수 설계

## 1. 책임 경계

| 작업 | 담당 |
|---|---|
| 온보딩 답변 구조화 | AI + schema/domain validator |
| 상품 후보 점수 계산 | Rules Engine |
| 후보 선정 이유 설명 | AI, 계산된 점수를 입력으로 사용 |
| 판매가·마진 계산 | Pricing Engine |
| 상품 설명·SEO·SNS 초안 | AI |
| 주문 자동 승인/차단 | Rules Engine |
| 외부 게시 | 승인된 명령을 실행하는 adapter |

AI가 숫자를 출력하더라도 원가, 권장 판매가, 예상 마진의 최종 값은 서버가 다시 계산해 덮어쓴다.

## 2. Brand Profile

온보딩 질문은 다음 축을 채워야 한다.

1. 브랜드명과 한 문장 소개
2. 대상 국가와 콘텐츠 언어
3. 고객 연령대·관심사·구매 동기
4. 브랜드 성격과 피해야 할 인상
5. 시각 스타일과 핵심 색상
6. 대표 제품군과 초기 상품 수
7. 목표 가격대와 통화
8. 허용 마진 하한
9. 디자인/상표 자산 보유 여부
10. 배송·반품 약속 범위
11. 지속가능성 등 근거가 필요한 주장
12. 금지 표현과 경쟁 브랜드 참조

AI는 빠진 정보를 임의의 사실로 채우지 않는다. 선택적 필드는 `null` 또는 빈 배열을 사용하고 `assumptions`에 추정 사항을 표시한다.

## 3. 상품 점수

사용자 초안의 표현을 양의 가중치 합으로 정규화한다.

`score = 0.30M + 0.25T + 0.15S + 0.15D + 0.10V + 0.05R`

각 부분 점수는 0~100이다.

- `M margin`: 보수적 공헌 마진율을 구간 또는 연속 함수로 변환
- `T target_fit`: 온보딩 선택지와 제품 taxonomy의 명시적 매핑
- `S shipping`: 대상 국가 배송 가능성, 예상비, 제작·배송 기간
- `D design_fit`: 지원 placement, 인쇄 면적, 색상/기법 적합성
- `V variety`: 유효한 사이즈·색상 수와 목표 고객 커버리지
- `R return_safety`: 반품 위험이 낮을수록 높은 점수. 사이즈 복잡성과 품질 변동 proxy 사용

초안의 `- 타깃 적합성` 표기는 감점 의미로 해석하지 않고 가중 항목 구분 기호로 해석했다. 실제로 감점식이 의도였다면 구현 전에 결정 기록을 변경해야 한다.

## 4. 점수 데이터 규칙

- 모든 점수에 `value`, `evidence`, `source_timestamp`, `rule_version`을 저장한다.
- 데이터가 없으면 LLM 추정값을 넣지 않고 `unknown`과 confidence를 기록한다.
- 배송 불가, 원가 미확인, 디자인 placement 불가 같은 hard constraint는 총점과 관계없이 후보에서 제외한다.
- target fit처럼 제품 정책 기반 점수는 관리 가능한 lookup table로 시작한다.
- 실제 판매/반품 데이터가 쌓이기 전에는 “판매 예측”이라고 부르지 않는다.

### 초기 마진 점수 예시

| 보수적 마진율 | 점수 |
|---:|---:|
| 60% 이상 | 100 |
| 50~59.99% | 85 |
| 40~49.99% | 65 |
| 30~39.99% | 35 |
| 30% 미만 또는 음수 | 제외 |

이 구간은 가정이며 Printful 실제 원가·배송비와 사용자 목표 가격을 이용한 표본 분석 후 확정한다.

## 5. 콘텐츠 생성 파이프라인

1. 승인된 Brand Profile과 선택된 candidate revision을 입력으로 고정한다.
2. 금지 표현, 사실 근거, 길이, 대상 locale을 프롬프트에 포함한다.
3. Structured Outputs로 `product-content.schema.json` 계약을 받는다.
4. JSON Schema와 도메인 규칙을 검증한다.
5. 가격/마진을 Pricing Engine 계산값으로 채운다.
6. 상표·과장 주장·금지어 검사를 수행한다.
7. 사용자 검수용 diff와 경고를 생성한다.

## 6. 품질 평가 세트

출시 전 최소 30개 브랜드 fixture를 만든다. 패션/굿즈, 미국/일본, 저가/중가, 정보 누락, 충돌 입력, 한국어/영어 혼합을 포함한다.

평가 항목:

- schema 및 domain validation 통과율
- 입력 사실 보존과 환각 여부
- 브랜드 voice 일관성
- SEO 제목·설명 길이와 중복
- 제품 간 제목/설명 중복률
- 금지 주장 및 상표 위험 표현
- 계산 가격과 AI 텍스트에 적힌 가격의 일치
- 사람의 수정량과 승인율

프롬프트나 모델 변경은 이 평가 세트에서 기준선보다 악화되지 않을 때만 배포한다.
