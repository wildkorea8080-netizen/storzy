# 주문 대조 실행 상태의 워크스페이스 격리

주기 주문 대조 실행은 여러 워크스페이스를 한 번에 처리하지만, 관리자 화면의 상태·이력·경고는 현재 워크스페이스 결과만 사용한다.

- 실행 상태와 이력은 `results` JSON 배열에 현재 `workspaceId`가 포함된 실행만 조회한다.
- 운영 현황의 실패·실행 지연 경고는 현재 워크스페이스의 가장 최근 완료 결과를 기준으로 계산한다.
- 아직 완료되지 않은 전역 `RUNNING` 실행은 모든 Shopify 연결 워크스페이스에 적용하되, 2시간 이상 정체된 경우에만 경고한다.
- 정상 실행 중에는 최초 실행 전 또는 26시간 초과 경고를 잠시 숨겨 실행 완료를 기다린다.

따라서 다른 워크스페이스의 Shopify API 실패가 현재 워크스페이스의 실패 경고나 실행 이력으로 노출되지 않는다.
