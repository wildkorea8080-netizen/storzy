# 주문 대조 운영 코드 한글화

주문 대조 화면은 API와 데이터베이스의 내부 코드를 유지하면서 화면 표시만 한글 운영 용어로 변환한다.

- 이슈: 로컬 누락 주문, 취소 상태 불일치, 결제 상태 불일치
- 상태: 처리 필요, 확인 중, 해결 완료
- 작업: 확인 접수, 수동 해결, 자동 해결, 안전 재수신, 취소·결제 상태 반영
- 시스템 실행자: 자동 스케줄러, 관리자 화면

변환 모듈은 정확히 일치하는 알려진 코드만 치환한다. 알 수 없는 신규 코드는 원본을 표시하고, 주문 ID·담당자 ID·운영자가 작성한 사유는 변경하지 않는다.
