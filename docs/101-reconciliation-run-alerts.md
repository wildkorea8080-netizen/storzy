# 주문 대조 실행 장애 경보

운영 현황은 가장 최근 주문 대조 실행이 다음 조건에 해당하면 `ORDER_RECONCILIATION_RUN` 경보를 표시한다.

- `PARTIAL`: 일부 Shopify 워크스페이스 실패
- `FAILED`: 실행 또는 전체 워크스페이스 실패
- `RUNNING` 상태로 2시간 초과: 프로세스 중단 가능성이 있는 정체 실행

정상 완료된 과거 실행이 아니라 가장 최근 실행만 평가해 이미 회복된 장애가 계속 표시되지 않도록 한다. 정체 실행은 저장 상태를 즉시 변경하지 않고 경보만 표시하며, 다음 스캐너가 advisory lock을 획득하면 중단 원장 복구 정책에 따라 실패로 종결한다.

경보에는 실행 원장 ID와 상태 코드만 사용하며 credential, 주문 원문이나 고객 개인정보는 포함하지 않는다. 관리자는 경보를 선택해 주문 관리 화면의 마지막 주기 대조 상태를 확인할 수 있다.
