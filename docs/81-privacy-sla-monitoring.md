# 개인정보 요청 SLA 모니터링

Shopify 개인정보 요청은 수신 후 30일 이내 처리를 기본 기한으로 관리한다. 운영자가 위험 요청을 빠르게 찾도록 관리자 개인정보 화면에 다음 집계를 표시한다.

- 처리 대기
- 검토 중
- 7일 이내 마감
- 기한 초과
- 처리 실패
- 가장 가까운 처리 기한

## API

`GET /api/admin/privacy-requests/summary`

관리자 인증이 필요하다. `workspaceId` 쿼리 파라미터가 있으면 해당 워크스페이스만 집계하고, 없으면 전체 요청을 집계한다.

기한 위험 집계에는 `PENDING`, `IN_PROGRESS`, `FAILED` 상태만 포함한다. `COMPLETED`와 `RETAINED_LEGAL` 요청은 기한 초과 경고에서 제외한다.

이 단계는 화면 기반 모니터링이다. 다음 운영 고도화에서는 외부 알림 채널과 주기 실행 스케줄러를 연결한다.
